# Эмодзи-шифр 🔐

Игра-викторина для школьников 4–8 классов: по цепочке эмодзи нужно расшифровать название мультфильма, фильма, книги, сказки, пословицу или фразеологизм.

**Играть:** https://gennadypiftankin.github.io/emoji-shifr/

## Что внутри

- **243 шифровки** в шести темах: сказки и басни, мультфильмы, фильмы, книги (в том числе школьная программа), пословицы, фразеологизмы. Три уровня сложности.
- **Подсказки разных видов:** картинка-сценка из эмодзи, описание, «другими словами», перевод на другой язык (английский, немецкий, французский, датский, шведский, итальянский, латынь), перевёртыш (слова заменены на противоположные), цитата, загадка, «откуда это» и первые буквы. Каждая подсказка уменьшает награду.
- **Проверка ответа прощает** опечатки, «ё/е», порядок слов и лишние слова вроде «мультфильм …», а «холодно — тепло — горячо» показывает, насколько игрок близко.
- **Монеты:** 10 / 20 / 30 за лёгкую / среднюю / сложную шифровку, бонус за серию.
- **Гардероб:** 135 предметов — 15 цветов, шапки, очки, лицо, одежда, аксессуары, предметы в руках, обувь, питомцы, эффекты и 10 танцев.
- **Игра с друзьями:** комната с кодом из 4 цифр или ссылкой. Все видят персонажей друг друга в их одежде. Кто быстрее расшифрует — получает бонус за место. Персонажи танцуют, падают в обморок, плачут, тают и хлопают в ладоши.

## Как это устроено

Статический сайт без сборки: HTML, CSS и JavaScript без фреймворков.

- Прогресс, монеты и одежда хранятся в `localStorage` браузера; в настройках есть код для переноса прогресса на другое устройство.
- Игра с друзьями работает через бесплатные публичные MQTT-брокеры (HiveMQ, EMQX, shiftr.io, Mosquitto) по WebSocket, без регистрации. Первая цифра кода комнаты определяет брокер. Ведущий хранит состояние игры, игроки публикуют своё «присутствие»; если ведущий уходит, ведущим становится следующий игрок.
- Для тестов с локальным брокером: `?broker=ws://127.0.0.1:9001`.

Файлы: `js/data/*.js` — шифровки, `js/match.js` — проверка ответов, `js/avatar.js` — персонаж и гардероб, `js/net.js` — комнаты, `js/app.js` — экраны и логика.
